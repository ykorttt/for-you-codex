# 오미쿠지 시뮬레이터 (おみくじ)

일본어 수업용 오미쿠지 뽑기 웹페이지입니다. 폰을 흔들면 통에서 막대가 나오고, 막대 번호에 맞는 운세 종이를 볼 수 있어요.

- 파일 하나(`index.html`)로 동작합니다. 설치할 것이 없습니다.
- 운세 7단계: 大吉 → 吉 → 中吉 → 小吉 → 末吉 → 凶 → 大凶
- 운세 종이마다 총운과 연애운(恋愛)·학업운(学業)·건강운(健康)·금전운(金運)이 한국어로 나옵니다.
- 운세 이름(大吉 등)은 한자와 읽는 법(だいきち), 한국어(대길)를 함께 보여 줍니다.
- 凶·大凶이 나오면 「おみくじを結ぶ」(신사에 묶고 가기) 버튼이 생깁니다.

## 진행 순서

1. 폰을 흔든다 (5번 흔들면 막대가 나옴). 흔들기가 안 되는 기기에서는 통을 톡톡 눌러도 됩니다.
2. 통이 뒤집히면서 막대가 나오고 번호가 보입니다. 예: 第十八番(だいじゅうはちばん) 18번
3. 「おみくじを受け取る」를 누르면 운세 종이가 펼쳐집니다.
4. 「もう一度引く」로 다시 뽑기 (횟수 제한 없음).

## 학생들에게 배포하기

폰의 흔들기 센서는 **https 주소에서만** 동작합니다. 아래 두 방법 모두 https 주소를 무료로 줍니다.

### Cloudflare Workers (추천)

저장소에 `wrangler.jsonc`가 들어 있어서, Cloudflare에 이 저장소를 한 번 연결해 두면 push할 때마다 자동으로 다시 배포됩니다.

1. [Cloudflare 대시보드](https://dash.cloudflare.com/?to=/:account/workers-and-pages) → **Workers & Pages** → **Create application**
2. **GitHub** 선택 → `ykorttt/for-you-codex` 저장소 선택 (처음이면 GitHub 연결 권한을 허용)
3. 설정 화면에서
   - 프로젝트 이름: 기본값 `for-you-codex` 그대로 (`wrangler.jsonc`의 `name`과 같아야 함)
   - 브랜치: 이 파일이 있는 브랜치 (`main`이 비어 있다면 꼭 바꾸기)
   - Build command: 비워 두기
   - Deploy command: `npx wrangler deploy` (기본값 그대로)
4. **Save and Deploy** → 1분쯤 뒤 `https://for-you-codex.<내 계정 이름>.workers.dev` 로 접속
   (주소는 Workers & Pages → `for-you-codex` 화면의 **Visit** 버튼에서도 볼 수 있어요)

`index.html`만 공개되고 README·설정 파일은 올라가지 않습니다(`.assetsignore`).

### GitHub Pages

1. GitHub 저장소 → **Settings** → **Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: 이 파일이 있는 브랜치, 폴더는 `/ (root)` → **Save**
4. 1~2분 뒤 `https://ykorttt.github.io/for-you-codex/` 로 접속

주소를 QR 코드로 만들어 칠판에 띄우면 학생들이 바로 들어올 수 있습니다.

### 기기별 참고

- **아이폰**: 처음에 「흔들기 켜기」 버튼을 눌러 동작 센서를 허용해야 합니다. 거절했다면 사파리를 완전히 닫았다가 다시 열면 다시 물어봅니다.
- **안드로이드**: 별도 허용 없이 바로 흔들 수 있고, 흔들 때 진동이 옵니다.
- 세게 흔들다 화면이 가로로 돌아갈 수 있어요. 화면 자동 회전을 꺼 두면 편합니다.
- PC(전자칠판)에서는 통을 클릭하면 흔들기 대신 동작합니다.

## 고치는 법

`index.html` 아래쪽 `<script>` 맨 위에 설정과 운세 문구가 모여 있습니다.

### 설정 (`CONFIG`)

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| `shrineName` | `にほんご神社` | 운세 종이 맨 위의 신사 이름 |
| `shakesNeeded` | `5` | 막대가 나오기까지 흔드는 횟수 |
| `shakeThreshold` | `13` | 흔들림 감도. 낮추면 살짝만 흔들어도 인식 |
| `seed` | `2026` | 번호 ↔ 운세 배치. 바꾸면 배치가 새로 섞임 |

### 확률 (`LEVELS`의 `sticks`)

막대는 모두 100개이고, 각 운세의 `sticks` 값이 그 운세가 적힌 막대 수입니다. 합계가 곧 번호 범위가 됩니다.

| 운세 | 막대 수 | 확률 |
| --- | --- | --- |
| 大吉 대길 | 10 | 10% |
| 吉 길 | 15 | 15% |
| 中吉 중길 | 15 | 15% |
| 小吉 소길 | 15 | 15% |
| 末吉 말길 | 15 | 15% |
| 凶 흉 | 15 | 15% |
| 大凶 대흉 | 15 | 15% |

번호와 운세는 고정으로 짝지어져 있어서, 반 친구 둘이 같은 번호를 뽑으면 같은 종이가 나옵니다(실제 오미쿠지처럼).

### 운세 문구

각 운세의 `love`·`study`·`health`·`money`에 문구가 3개씩 있고, 막대 번호에 따라 그중 하나가 정해집니다. `head`는 굵게 나오는 한 줄, `text`는 그 아래 풀이입니다.

```js
{ head: '노력이 열매를 맺는다', text: '한 만큼 확실히 결과가 나와요. 이번 시험, 기대해도 좋아요!' },
```

운세 이름 아래의 한자 뜻 풀이(`meaning`)에서는 `漢字{よみ}` 형식으로 쓰면 후리가나가 붙습니다.
